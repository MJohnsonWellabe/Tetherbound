# archive/

Historical material kept for reference, not for routing current work.

- `reports/` — markdown summaries and verdicts from past evidence runs
  (Gate F runs, visual-judge rounds, audits). The image/telemetry payloads
  that accompanied them are not kept in the tree; they remain retrievable
  from git history at commit `cf535cce` under `ralph/reports/`.

Nothing in this directory is authoritative. Start from `docs/` instead.
