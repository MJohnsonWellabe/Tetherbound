# Meadows Wild Build Instructions For Claude

## Mission
Use this folder to make the Meadows wild roster canon and build against it.

## What this folder gives you
This folder gives you:
- canonical names
- canonical roster composition
- canonical evolution rule
- canonical scale rule
- final reference art
- final species distinction rules

## What you should do
1. Read `20_MEADOWS_WILD_CANON_DIRECTIVE.md`.
2. Read `21_MEADOWS_WILD_ROSTER_CANON.md`.
3. Read `22_MEADOWS_WILD_ROSTER_ART_MAPPING.md`.
4. Treat the five PNG files as the visual reference package for Meadows wild Pals.
5. Update any Meadows implementation assumptions to match this pack.
6. If you generate/build/reference Meadows wild Pals, use these names and identities exactly.
7. If you create folders, filenames, docs, or asset IDs, use the canonical names from this pack.

## Design constraints you must preserve
- Only **one** Meadows evolution exists: `Mudsnout -> Tuskroot`
- Starters are excluded from this roster
- Meadowhart must not read like the legendary
- Trailpup must not read like the Ground starter
- Galecrest must not read like the Air starter
- Average scale should feel around player-world scale
- The roster should read clearly at third-person gameplay distance
- One cohesive stylized PBR language across all 13 species

## If old docs conflict
If an older exploratory doc conflicts with this pack:
- flag the conflict
- preserve this pack as current canon
- update implementation assumptions toward this pack rather than away from it

## If repo docs should be updated
If you are allowed to edit repo docs, update Meadows wild-roster references so they align with:
- the canonical species list in this folder
- the Mudsnout -> Tuskroot evolution rule
- the distinct-deer / distinct-canine / distinct-raptor rules
- the scale rule established here
