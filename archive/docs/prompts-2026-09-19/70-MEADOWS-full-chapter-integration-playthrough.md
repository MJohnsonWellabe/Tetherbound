# MEADOWS-FULL-CHAPTER — Final 3–4 hour integration, pacing and quality pass

## Goal
Run, measure and tune the complete Meadows from fresh launch through post-Warden world change as one uninterrupted game chapter.

This is not a feature-creation free-for-all. By the time this prompt runs, Gates A–E should have assembled the chapter. This prompt finds integration failures, pacing problems, dead travel, economy issues and quality gaps that only become visible over the whole run.

## Required start state
Use a fresh normal save through the actual title/front door. Do not use debug warps except for targeted reproduction after the full-run finding is recorded.

## Required end state
Warden defeated, legendary resolved, release ceremony handled if required, Meadows world healing/state change visible, and post-win acknowledgment/next-world hint functioning.

## Target length
Focused first completion: approximately **3–4 hours**.

Exploration-heavy/catching/building runs may be longer.

Do not hit the target by cutting required progression bands, shrinking the terrain footprint, skipping the tournament, deleting the Warrens/Relay/captains, or removing the stronghold finale. Use the intended levers:
- XP curve;
- trainer difficulty;
- material costs;
- travel time;
- spawn density;
- encounter placement;
- objective clarity;
- remove dead walking.

## Instrument the whole run
Record timestamps for at least:
- title/start;
- starter chosen;
- first catch;
- first level-up;
- functional home/rest learned;
- tournament start/win;
- South Bridge crossing;
- first Rootstone;
- Warrens entry/guardian clear;
- river discovery;
- Relay start/Captain Vance defeat;
- crossing restored;
- first Ironwood/riding payoff;
- captain 1/2/3;
- Hall approach open;
- Hall entry;
- Warden start/defeat;
- legendary decision;
- post-win state.

## Team timeline
At every major beat record:
- five slots / party composition;
- levels;
- HP/condition;
- important moves/TMs;
- bond/Best Creature where relevant;
- releases/replacements and why;
- evolution status;
- whether player felt pressure to change the five.

## Opportunity timeline
For every region record:
- wild encounters seen;
- trainers;
- resource clusters;
- optional discoveries;
- special encounters;
- camp/rest opportunities;
- main objective transitions;
- longest interval with no meaningful interaction or visual pull.

## Pacing questions
After each band answer:
- What was I trying to become ready for?
- How did my team improve?
- What tempted me off the path?
- Did I ever stop because of injury/night/preparation?
- Did gathering have known purpose?
- Did rewards matter?
- Did the region look/play differently from the prior one?
- Was there dead travel?

## Difficulty
Check:
- early fights teach without trivial boredom;
- tournament feels earned;
- Warrens guardian is a step up;
- Relay gauntlet/Vance is significant;
- regional captains test mature team composition;
- Warden is the climax;
- optional content provides useful power without making required content trivial.

No player scaling.

## Economy
Track:
- Orbs spent/remaining;
- coins earned/spent;
- Wood/Stone/Fiber/Berries;
- Rootstone/Ironwood;
- build costs;
- potions/revives;
- TMs found/used;
- resources that accumulate with no purpose;
- points where required preparation becomes grind.

## Reliability
Any repeatable freeze, input loss, bad save/load, impossible snap, broken gate, invisible blocker, missing collision, stuck objective or state duplication is a stop-the-line issue for the relevant segment.

Fix root cause and rerun at minimum the owning evidence gate before resuming the full run.

## Visual/world quality
Capture representative frames of:
- starting village/home;
- open Lower Meadows;
- approved lush pond pocket;
- quarry/Warrens region;
- river/Relay;
- Upper Meadows high pasture/old growth;
- stronghold approach;
- Hall exterior/interior;
- night with/without equipped torch as appropriate;
- post-Warden healed world.

Verify intentional variation inside one coherent biome.

## Controller / target hardware
Run on/against the Windows + ROG Ally target path where available.

Audit:
- all visible actions usable;
- menu focus/readability;
- frame/performance hotspots;
- loading/boot;
- map/minimap usability;
- combat/catching camera/control;
- build mode controls.

Use R9.1/R9.2/R9.3 findings as concrete polish tasks after the chapter is assembled, not as excuses to reopen functioning systems without evidence.

## Triage order for findings
1. freeze/data loss/progression blocker;
2. broken core verb;
3. unclear objective/gate;
4. dead/empty traversal;
5. progression/economy/difficulty problem;
6. creature/team attachment weakness;
7. regional content identity;
8. visual/UI/performance polish.

Fix highest-impact player problem first.

## Final acceptance
A fresh run should demonstrate:
- clear motivation from opening through finale;
- reliable core verbs;
- visible/meaningful team growth;
- repeated roster temptation and real five-slot pressure;
- enough creatures/trainers/resources/optional encounters to prevent dead running;
- natural camp/rest utility;
- useful rewards/material tiers;
- distinct regional places connected into one world;
- strong tournament, Warrens, Relay, captain and Warden milestones;
- satisfying legendary/release outcome;
- visible world healing;
- focused completion around 3–4 hours;
- acceptable target-hardware operation.

## Definition of done
The Meadows is no longer judged as a collection of completed backlog items. It is judged as a complete first game chapter that a player would voluntarily keep playing.
