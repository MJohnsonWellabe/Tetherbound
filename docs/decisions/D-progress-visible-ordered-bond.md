# Visible progression: retain the ordered bond ladder

2026-09-05. Prompt 73 §2.4 decision, explicitly selected by the orchestration
owner for this implementation: **option 2, keep the order and show all five**.

The five existing targets, their order, bond effects, evolution eligibility,
creature ownership and save counters remain unchanged. Every credited action
emits feedback immediately, including feeding before the first combat milestone.
The Team detail lists all counters, labels the next required shared action, and
explains that a completed later task waits for the earlier task. Completing the
earlier task can therefore celebrate more than one already-earned node together.

This is a presentation change, not silent retuning of bond or evolution. The
Cloudreach authored Fly-route completion bonus is the separately requested small
25 m travel-task credit to the active owned companion, awarded only when the
existing physically verified landing commits a new canonical completion event.
It adds no sixth task, new creature slot, or repeatable landing farm.
