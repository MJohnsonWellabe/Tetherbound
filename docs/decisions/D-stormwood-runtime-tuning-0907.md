# Stormwood runtime tuning — 2026-09-07

Following the owner's instruction to adopt conservative defaults without pausing,
the authored Surge uses 240/90/120/60-second Calm/Building/Break/Fading phases;
gentle regions lengthen Calm by 1.35, disabled rods lengthen Calm by 1.5 and
shorten Break to 0.6, while aftermath uses 2400/45/45/60. These are tunable
implementation values, not a claim of accepted pacing. Canopy protection uses
measured live leaf envelopes from the installed tree models; removing a tree
removes its protection. Continuous envelopes intentionally protect beneath small
alpha-card gaps. Crown-grade Stormglass is a distinct inventory grade of the
same resource, restricted to the Capacitor Grove and Hollow Crown, so ordinary
Stormglass cannot silently satisfy the mandatory Crown connection's grade cost.
