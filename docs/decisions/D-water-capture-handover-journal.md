# Water capture handover journal

Aquaryn's host resolution must save the exact caught instance and stable catcher identity before confirming the catch. A disconnect during the animation or the existing five-creature release choice must not lose the Alpha or grant another copy. The world therefore retains one inaccessible pending handover record; the named character resolves it through the existing five-slot choice, and saves a personal receipt together with the resulting party before acknowledging it. Replays with that receipt only acknowledge. This is a transaction journal, not ownership or creature storage: it provides no deployable, rideable or transferable sixth creature, and does not change the five-creature cap. A failed character save restores the same party object identities and leaves the choice pending. A failed world acknowledgment save retains the claim for receipt-protected replay. Existing ordinary catches keep their established behavior.
