# Water: publish only the skill level needed by host arbitration

The existing portable-character model makes the character owner authoritative for personal progression. Preserve that model: Skills XP and Candy remain in PlayerState/CharacterSave, and only Catching level is added to the existing owner-authorized trainer proxy, using reliable on-change replication and the spawn snapshot. The host clamps that typed level through PlayerSkills, derives the configured bonus, and rolls the catch itself; throw intents cannot submit a bonus or outcome. Other skill benefits drive the owner's existing traversal simulation, so transmitting all five XP records every movement frame would add traffic without an authoritative consumer. This narrows the Phase 0 summary contract without adding a second network protocol. Real two-peer evidence is still required.
