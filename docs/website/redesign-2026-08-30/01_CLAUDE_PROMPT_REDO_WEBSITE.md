# Claude Prompt — Tetherbound Website Redesign

Replace the current Tetherbound website with a much simpler, image-first landing page based on the attached website art board.

## Non-negotiable rule
The art board is a layout/style reference only. Do not use or recreate any environment art from the board unless the shipped game genuinely looks like it.

Use real in-game screenshots from the current build for all environment, exploration, combat, building, village, Hall, and world imagery.

Creature/character artwork may only be used where it accurately represents assets already in the game or assets actively being implemented.

Do not exaggerate the current visual quality of the game.

## Remove
- Steam wishlist language
- Steam buttons/icons
- Fake social/community links
- Detailed chapter roadmap
- Long story exposition
- Patch-note style homepage content
- Exact 3–4 hour chapter claims
- Technical/development explanation that does not help sell the game

## Visual direction
- Dark, premium game-site presentation
- Large screenshots
- Very little body copy
- Strong typography
- Dark gradients over screenshots for readability
- Tether teal as a controlled accent
- Meadows green/gold for friendly sections
- Oxblood for Team Tether sections
- Avoid excessive cards, borders, and UI chrome
- Let the screenshots carry the page
- Mobile-first responsiveness matters

## Screenshot selection rule
Before coding, inspect the repo for the newest and strongest current in-game captures. Prefer current captures over old site images.

If a section does not have a good enough real screenshot, do not invent one. Use the strongest available honest image and note what future capture would improve that section.

## Goal
The finished homepage should make Tetherbound look polished and exciting without promising visuals the current game does not have.

It should communicate the game in under 30 seconds:
- creatures
- exploration
- five-creature commitment
- real-time combat
- building
- Team Tether
- repairing a broken world
