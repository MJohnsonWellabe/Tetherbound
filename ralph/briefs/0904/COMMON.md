You work autonomously: never stop to ask a question — if a decision is needed, make the smallest defensible call, record it in your report, and continue.

**Git.** `git fetch origin && git checkout -B <your-branch> origin/main`. Commit early and often with clear messages; push with `git push -u origin <your-branch>` (retry with backoff on network errors). Never push to `main`, never rebase or force-push, never touch a file outside your ownership list (if you must, stop that sub-item and say so in the report — the coordinator routes it). CI runs on every `ralph/**` push; a run under five minutes verified nothing. Known red on `main` at your start: `verify-unit-tests (3)` fails on `test_item_icons.gd` for six missing candy/mushroom icons — another lane owns that; do not fix it, do not add those icons.

**Godot in this container.** There is no Godot binary preinstalled. Install it first (about a minute):
```
mkdir -p ~/godot-bin && curl -sSL -o /tmp/godot.zip https://github.com/godotengine/godot/releases/download/4.7-stable/Godot_v4.7-stable_linux.x86_64.zip && unzip -q /tmp/godot.zip -d /tmp && mv /tmp/Godot_v4.7-stable_linux.x86_64 ~/godot-bin/godot && chmod +x ~/godot-bin/godot && export PATH=$HOME/godot-bin:$PATH && cd <repo> && godot --headless --path . --import 2>&1 | tail -5
```
Put `export PATH=$HOME/godot-bin:$PATH` on every later shell command (shell state does not persist). Unit: `godot --headless --path . --script tests/run_tests.gd -- --only=<file.gd>` (the full suite is ~28 min; run it only if your brief says so). Smoke: `godot --headless --path . --script tests/smoke_<name>.gd`, then grep the log for `^ERROR:` and `SCRIPT ERROR` and read them (a known-benign set exists; the set must not grow). Renders: `apt-get install -y xvfb mesa-utils libgl1-mesa-dri >/dev/null 2>&1; xvfb-run -a -s "-screen 0 1280x720x24" godot --path . --rendering-driver opengl3 --resolution 1280x720 --script <capture script>` — NEVER `--headless` together with a rendering driver (it hangs). Software GL captures of the full world take 20–50 min each; budget for it and never run two renders at once. Re-import after any asset change before capturing.

**Tests exercise real behaviour.** No test may pass by grepping a script's source text. A green test is not evidence until you have seen it fail for the right reason (temporarily break the behaviour, watch it go red, restore). Address inventory by item identity, never slot index.

Prove by number where you can (crop medians, luminance ratios) decided before the render. Commit the written verdict and at most one contact sheet per round named `_sheet*.png` under `ralph/reports/<LANE>/`; never commit per-frame PNGs or telemetry. Stop after two rounds that move nothing and record the ceiling.

**Status doc hygiene.** Record findings in `docs/CURRENT_STATE.md` (rewrite the relevant row, do not append layers) and decisions in `docs/decisions/`. Never edit `docs/owner/*`.

**Finish with a report** at `ralph/reports/<LANE>/REPORT.md` (committed and pushed) containing: files changed; functionality implemented in player-visible terms; every test/smoke run with its exact command and pass/fail counts; runtime validation performed; frames and the blind-judge verdict if visual; known limitations and what you deliberately did not do; final commit hash and branch. Then end your session with the same summary as your last message. A report without a commit hash is not complete; a claim your branch cannot reproduce is treated as failed.
