# Stormwood detiling parity disposition

The two-line Terrain3D detiling parity candidate is withdrawn. The source binding was technically valid, but the matched Stormwood material-only comparison produced no meaningful overall preference. Keeping an unproven runtime divergence would add configuration surface without a demonstrated scene-level benefit. The independent retained Stormwood vegetation palette is unaffected.

The exact withdrawn source delta is preserved in `stormwood-detiling-parity-held.patch`.
