   day/night set for the eight grass-linked locations with ordinary player/camera
   context. Verify the actual shipping scene contains terrain, structures, grass
   and route-verge passes; a harness missing geometry cannot be the baseline.
   Record capture/source/export IDs and any missing provenance. If an old defect
   no longer appears, preserve the working result rather than manufacture a fix.
2. Define one Cloudreach-only role distribution: most instances embedded low
   cover, fewer medium masses, a small fraction sparse tall accents in coherent
   irregular shoulder clumps. Preserve accepted route-verge stations, plantable
   patches, path/structure exclusions, collision and existing placement ceilings.
   Keep tall accents away from route centres and inhabited paving.
3. Replace the independent `1.6..2.3` X/Z grass override with width proportional
   to height using actual mesh dimensions, with role-specific bounded ratios.
   Put role proportions and dimensions in Cloudreach config. Define numeric
   acceptance bounds from baseline trainer-scale evidence before coding. A
   role-aware sampler and coherent mass distribution are required; changing
   scale endpoints alone is not this plan.
4. Implement one bounded candidate. Expected ownership:
   `scripts/world/cloudreach_ground_cover.gd`, the `ground_cover` block of
   `data/config/cloudreach_visual.json`, focused Cloudreach tests, and an isolated
   Cloudreach helper if necessary. Change the Cloudreach cover shader only if
   required to represent roles. Reuse the installed nature family. Preserve shared
   Meadows `grass_field.gd`, route-verge source, terrain overlays, clouds, cliffs,
   collision and gameplay. If another mechanism is necessary, submit a revised
   plan instead of widening this one.
5. Run focused generated-instance tests for deterministic distribution, role
   proportions, width/height bounds, tall-clump clearance, supported positions
   and unchanged ceilings. Exercise production construction, not source-string
   presence. Run relevant existing Cloudreach cover/environment smoke and the
   required world smoke; inspect `ERROR:` as well as script errors. Preserve

   ceiling. Do not declare that grass alone closes architectural FAIL locations.
