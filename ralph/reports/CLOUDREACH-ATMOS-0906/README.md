Closing the Cloudreach Cliffs atmosphere and verticality gaps: **C4** (thin horizon),
**C5** (floating islands read as unrendered slabs), **C3** (a region named for cliffs
never shows one), and the §5.2 leftovers that belong to this lane.

Branch `claude/art-cloudreach-atmosphere-0906`, from
`claude/second-biome-art-plan-470zru` (the merge + cliff option A + realm-wide turf fill
+ crown relief), not `main`.
