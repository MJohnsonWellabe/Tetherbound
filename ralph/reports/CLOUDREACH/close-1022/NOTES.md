- 2026-10-22 10:45 CT REPLY (F08#3 GPU weather confound). Root cause: not a shared RNG. `scripts/world/world_weather.gd` (Cloudreach `WorldWeather`) calls `_rng.randomize()` at `_ready` and rolls a new state every 240–480 s of frame time (`weather.json` cycle). It is unseeded by design, so no run of either arm is reproducible. The candidate builds more and takes longer to reach its frames, so it crossed a weather change the control did not. The settlement-life code has its own `RandomNumberGenerator` (cloud cards only) and never touches weather, so a "flag on/off at the same seed" test has no seed to hold. Fix: `tools/capture_cloudreach_settlement_identity.gd` now pins `clear` and stops the cycle before the first frame, and writes `# weather pinned clear` to the manifest. `tools/phase2_capture_locations.gd` already does the same. Co-op weather stays host-authoritative through the existing session RPCs; no gameplay change. Every GPU pair before this is weather-confounded. The r17 SHA (weather pin, door-lantern and road colour fix, near-field stone outcrops) follows after a CPU check.
