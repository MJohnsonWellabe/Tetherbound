## Separate look-candidate startup repair

The existing `detail_cull.gd` documents a Meadows message-queue overflow from this pattern. The repair collects geometry instance IDs and schedules one deferred flush per pending batch. It reads materials after builders assign them, ignores freed/departed nodes, and does not retain node references.
