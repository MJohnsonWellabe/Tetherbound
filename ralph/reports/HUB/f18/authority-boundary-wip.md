# Single admitted-character authority boundary — supporting WIP

The explicit portable projection is character ID, canonical party/loadout
mirror, typed redesign personal carrier, inventory and portal escrow. Session
validates before admission and retains the original host record on rejoin;
per-action inventory/rank proposals cannot refresh that baseline. Internal
mastery and loadout CAS arms validate whole candidate documents. Loadout owner
save locks retain the accepted edit until its exact UID/revision/receipt ACK.

Portal world receipt/key debit promotion is synchronous and hidden until the
existing atomic world write succeeds. Failure restores both the world ledger
and frozen admitted record; owner atomic character settlement then ACKs, with
pending escrow recovered from the owning world receipt on rejoin. Typed escrow
guards precede character/split/flat application and writing, preserving old
death-satchel semantics and schema version 28.

This source is a prototype, not acceptance. It has not yet been parsed or run.
Actual capture/release/evolution roster mutation, host travel permit/waystone
and Home return, protected boss reward batch settlement, owner write-loss and
disconnect/rejoin witnesses remain incomplete. New portal interaction nodes
are not yet attached to the live Hall. No new F18/F23 criterion is closed.
