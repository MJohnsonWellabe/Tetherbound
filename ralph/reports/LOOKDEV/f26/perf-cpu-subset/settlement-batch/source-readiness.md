## Helper boundaries relevant to implementation

The positive-determinant test at helper `:53` rejects mirrored/singular transforms but permits nonuniform scale/shear. `SurfaceTool.append_from` transforms normals, tangents and binormals with the same basis as positions; it does not apply an inverse transpose there ([Godot 4.7 surface_tool.cpp, lines 953–991](https://raw.githubusercontent.com/godotengine/godot/4.7-stable/scene/resources/surface_tool.cpp)). Consequently this helper is unsafe as a generic batcher for nonconformal inputs without an eligibility restriction or corrected attribute handling. The current 42-file source check found no such input; this is not evidence of a current kit shading defect. `_relative` also assumes ordinary inherited transforms and does not honor a `top_level` escape.

Eligibility rejects scripted/skipped/hidden subtrees, skins, blend shapes, overlays, instance transparency, begin ranges and selected object-space/alpha materials (`:128–203`). It does not establish that an unscripted mesh is static when an AnimationPlayer elsewhere targets it; the current glTF inputs have no animation tracks. It neither groups nor copies instance shader parameters, `lod_bias`, custom AABB, extra cull margin, visibility parent, occlusion override, or sorting settings. Those are real render properties ([GeometryInstance3D documentation](https://docs.godotengine.org/en/4.7/classes/class_geometryinstance3d.html)); no concrete nondefault use was found in the inspected eligible construction path. Keep the helper scoped to that path or explicitly reject unsupported inputs before claiming broader reuse. `_format_key` protects attribute presence but not custom-channel encoding; current input source has no custom attributes.

Material equality at `:225–247` caches storage-property hashes forever by instance ID. It intentionally shares the representative material across equal imported copies. A later mutation can invalidate a cached equality decision, and changing a hidden original's material will not redirect an existing batch. Nested resources compare by path/identity rather than recursively inspecting current contents. No such post-batch mutation was established here. A per-merge equality cache or an explicit immutable-material contract would avoid relying on undocumented lifelong immutability; this concern does not prove a current village defect. The static cache also has no eviction.
