# m50b: storm light grade, second try (CPU, code-blind, 27 Oct): WORSE (-0.44). The storm-grade approach is PARKED.

**Arms:** the same six stands and OFF frames as m50.
- **ON:** `storm_grade`, retuned:
  - the rim turned 62 degrees off the view axis (a three-quarter back light);
  - rim energy 0.9 / 1.3 / 1.8 / 1.1 by phase;
  - break graded brighter (1.06 / 1.14 / 0.9);
  - decorative bolts lift scene brightness by 0.35x the bolt level.

**Result:** mapped **6.05 -> 5.61 (-0.44)**. 3/3 judges prefer OFF: 5.6/5.3, 5.5/5.2, 5.8/5.6. Linear fit, no warnings.
- **No rim:** PRESENT on both arms 3/3.
- **The storm does not carry into the scene:** PRESENT/PARTIAL on ON, PARTIAL on OFF.

**Why:**
- Lifting the break removed the calm-to-break value change, which the judges credit on OFF as "a real phase shift, darker".
- The three-quarter diffuse rim still lights no edge the judges can see at contact-sheet size.
- The bolt lift brightens the frame evenly, so it reads as a lighter grade rather than light landing on trunks.
- What the judges want, a hard white-violet edge on trunks and figures at the strike, needs a per-material rim or fresnel term, not one more directional light. In Compatibility that means touching the vegetation and character materials.

**Decision:** m50 (+0.04) and m50b (-0.44) are two misses, so the storm-light grade is **PARKED**. `storm_grade` stays OFF; no m50 arm is posted.
- **New idea threshold:** a material-level rim/fresnel on trunks, creatures and the trainer that flashes with bolts, keeping the darker break grade OFF already has. That touches shared vegetation and character shaders, so it is a scoped decision for the coordinator.
