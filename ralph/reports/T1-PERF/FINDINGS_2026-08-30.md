## The T3-INSTALL collision-streaming levers: verified wired

`performance.json`'s `collision_stream_radius_m` / `_interval_s` / `_cell_m`
were re-tested by directly changing each value and re-measuring with
`tools/perf_profile.gd`, not by reading the code and trusting the comment:

| config change | measured effect |
|---|---|
| `collision_stream_radius_m` 100→30 | resident colliders: village 151→0, band1 410→2 |
| `collision_stream_interval_s` 0.5→2.0 | profiler's own reported sweep rate: "2.0 Hz"→"0.5 Hz" |
| `collision_stream_cell_m` 32→16 | sweep cost stayed low, consistent with the smaller radius (not independently isolated from the radius change) |

All three restored to shipped defaults (100.0 / 0.5 / 32.0) immediately after.
**Verdict: correctly wired.** This item, at least, is not part of OP-0830-6.
