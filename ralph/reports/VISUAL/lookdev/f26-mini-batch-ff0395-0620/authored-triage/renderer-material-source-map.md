## Interpret the JSON fields first

- A null **mesh_source_material** with a non-null **active_material** is normal for geometry finished through `material_override`. A null overlay is normally optional. Neither proves a missing material.
- An empty generated Resource/Shader/Texture path is normal for `new()` / `ImageTexture.create_from_image()` / NoiseTexture2D. Match class, shader hash and caller rather than requiring an external file for every object.
- StandardMaterial3D has many optional texture properties: absent albedo on deliberately solid-colour metal/glass/glow is authored; absent normal/ORM on foliage may be authored. This is not permission to ignore a missing texture explicitly assigned by the owning source.
- A null **active_material** is not automatically intentional even on a PrimitiveMesh. Review the exact assignment path below. I found no blanket rule authorizing all active nulls in these families.
- A Terrain3D builtin shader RID/name list is distinct from an enabled override. Generated terrain arrays and prior silent substitutions remain unproved by that list; preserve native warnings plus source/install receipts.
